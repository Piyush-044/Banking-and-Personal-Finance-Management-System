# Banking and Personal Finance Management System

A modern, high-aesthetic web interface for a **Banking and Personal Finance Management System** built with **100% Pure HTML5 and CSS3** (No JavaScript or external frameworks).

## 📌 Project Overview & Scope
This project covers **40% completion** (Phase 1 core modules) of a full Banking & Personal Finance system as requested.

### 🌟 Features Built (40% Scope)
1. **Global App Navigation & Layout Shell**:
   - Responsive sidebar with active status indicators and scope progress tracking widget.
   - Glassmorphic top navigation bar with user profile, search bar, and notification icons.
2. **Dashboard Overview (`index.html`)**:
   - Financial Net Worth, Monthly Income, Expenses, and Savings metric cards with percentage trends.
   - Pure CSS monthly cashflow analytics visual chart.
   - Platinum Credit Card visualizer with chip, card numbers, expiry, and logo.
   - Recent activity list with status badges.
3. **Accounts Management (`accounts.html`)**:
   - Account overview cards for Checking, High-Yield Savings (4.85% APY), Credit Card, and Wealth Investments.
   - Pure CSS Modal popup (`:target` pseudo-class) for opening a new bank account.
4. **Transactions & Transfers (`transactions.html`)**:
   - Detailed transaction log table with status badges (Completed, Pending) and category icons.
   - Filter bar and instant wire / UPI money transfer form panel.
   - Daily transfer limits visualizer.

### ⏳ Future Phase (Remaining 60%)
- **Budgets Module**: Categorized spending limits and monthly goal tracking.
- **Expenses Tracker**: Automatic expense categorization.
- **Reports & Statements**: PDF export statement generator and tax estimator.

## 🛠️ Tech Stack
- **HTML5**: Semantic tags, accessibility attributes, pure anchor routing.
- **CSS3**: CSS Custom Properties (Variables), Flexbox, CSS Grid, Glassmorphism, CSS-only animations & modal targeting.
