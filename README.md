# Banking and Personal Finance Management System

A clean, responsive web interface for a **Banking and Personal Finance Management System** built with **HTML5 and CSS3**.

## 📌 Features
1. **Dashboard Overview (`index.html`)**:
   - Total Balance, Monthly Income, Monthly Expenses, and Net Savings summary cards.
   - Recent Transactions table with status indicators.
   - Quick Money Transfer form.
2. **Accounts Management (`accounts.html`)**:
   - Everyday Checking, High-Yield Savings, Credit Card, and Investment Portfolio cards.
   - Form layout for opening a new bank account.
3. **Transactions & Transfers (`transactions.html`)**:
   - Detailed transaction log history.
   - Send Money / Wire transfer form.

## 🛠️ Tech Stack
- **HTML5**: Semantic layout structure.
- **CSS3**: Flexbox, CSS Grid, clean custom styles, responsive design.
